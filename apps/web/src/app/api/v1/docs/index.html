InPlain.AI API Documentation

v1.0.0

Getting Started

Welcome to the InPlain.AI API! This API provides programmatic access to privacy policy analysis, monitoring, and user watchlist management.

Authentication

All API requests require authentication using an API key. Include your API key in the x-api-key header:

x-api-key: your_api_key_here

Base URL

All API endpoints are relative to:

https://inplain.ai/api/v1

Rate Limits

  • Standard tier: 1,000 requests per day
  • Pro tier: 10,000 requests per day
  • Enterprise tier: Custom limits

Quick Examples

Get Company Info

curl -H "x-api-key: YOUR_KEY" \
  https://inplain.ai/api/v1/companies/facebook

Summarize Policy

curl -X POST -H "x-api-key: YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"policyText": "..."}' \
  https://inplain.ai/api/v1/policies/summarize

Get Recent Changes

curl -H "x-api-key: YOUR_KEY" \
  https://inplain.ai/api/v1/changes/recent?limit=10
