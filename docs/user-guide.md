# PolicyDiff User Guide

## Overview

PolicyDiff automatically monitors privacy policies and terms of service pages, tracking changes over time and providing AI-powered summaries to help you understand what changed and why it matters.

## Getting Started

### Viewing Monitored Companies

1. Visit the [PolicyDiff Dashboard](/) to see all currently monitored companies
2. Each company card shows:
   - Company name and monitored URL
   - Current monitoring status
   - Last check timestamp

### Exploring Policy Changes

1. Click on any company card to view their dedicated page
2. The company page displays:
   - **Latest Changes**: Most recent policy updates with AI summaries
   - **Change History**: Timeline of all detected changes
   - **Raw Diffs**: Detailed view of what text was added/removed

### Understanding Change Indicators

PolicyDiff categorizes changes into three levels:

- **Minor** 🟢: Small wording changes, typos, formatting updates
- **Moderate** 🟡: Notable changes that may affect some users
- **Major** 🔴: Significant changes that likely impact user privacy or rights

### Risk Assessment

Each change is analyzed for privacy impact:

- **Low Risk**: Clarifications, minor updates that don't affect user rights
- **Medium Risk**: Changes that may affect user experience or data handling
- **High Risk**: Significant changes to data collection, sharing, or user rights

## Features

### Real-time Monitoring
- Policies are checked hourly for changes
- New snapshots are automatically captured when changes are detected
- Diffs are generated and analyzed within minutes

### AI-Powered Summaries
PolicyDiff uses OpenRouter's legal-specialized AI models to provide:
- Plain-language summaries of what changed
- Key highlights of the most important updates
- Risk assessment for privacy impact
- Categorization of change types (data collection, user rights, etc.)

**Available AI Models:**
- Google Gemini 2.5 Flash (default) - Fast and cost-effective
- Meta Llama 3.3 70B - Advanced reasoning capabilities
- OpenAI GPT-4o Mini - Balanced performance
- Anthropic Claude 3 Haiku - Privacy-focused analysis
- Google Gemma 2 9B - Lightweight but accurate

You can select different models when generating summaries to get varied perspectives on policy changes.

### Change Categories
Changes are automatically categorized into:
- **Data Collection**: How companies collect your information
- **Data Sharing**: Who they share your data with
- **Data Retention**: How long they keep your data
- **User Rights**: Your rights regarding your data
- **Security**: How they protect your information
- **Cookies**: Cookie and tracking policies
- **Third Parties**: Third-party integrations and services
- **Children**: Policies specific to minors

## Adding New Sources

### Via CSV Upload (Admin)
To monitor new companies, add them to the `companies.csv` file:

```csv
slug,name,url,category,checkInterval,active
google,Google,https://policies.google.com/privacy,tech,3600,true
```

### API Integration
You can also add sources programmatically via the API:

```bash
curl -X POST /api/companies \
  -H "Content-Type: application/json" \
  -d '{
    "slug": "example-company",
    "name": "Example Company",
    "url": "https://example.com/privacy",
    "checkInterval": 3600
  }'
```

## Understanding the Data

### Snapshots
Each time a policy is checked, PolicyDiff creates a snapshot containing:
- Full text content of the policy page
- Capture timestamp
- Content hash for deduplication
- Metadata about the source

### Diffs
When changes are detected, PolicyDiff generates:
- HTML diff highlighting additions and deletions
- Change statistics (lines added/removed)
- Change type classification
- Links to relevant snapshots

### Summaries
AI summaries include:
- Concise explanation of changes (2-3 sentences)
- Key highlights (up to 5 bullet points)
- Risk level assessment
- Category tags for change types

## Best Practices

### Interpreting Changes
- Focus on **Major** and **High Risk** changes for immediate attention
- Review **Medium Risk** changes when you have time
- Use categories to filter for changes relevant to your interests

### Staying Informed
- Check the dashboard weekly for an overview of all changes
- Set up alerts (coming soon) for high-risk changes
- Bookmark company pages for policies you care about most

### Understanding Context
- Always read the full AI summary, not just the risk level
- Check the raw diff if you need exact details
- Remember that some changes may be positive (better privacy protections)

## Limitations

### Coverage
- Currently monitors 5 major tech companies (Google, Facebook, Amazon, Microsoft, Apple)
- English-language policies only
- HTML and PDF formats supported

### Detection
- Changes are detected at the text level
- Some formatting-only changes may be flagged
- Very minor changes (typos) might be missed depending on context

### AI Analysis
- Summaries are generated by AI and may occasionally miss nuances
- Risk assessments are best-effort and not legal advice
- Always review important changes yourself

## Troubleshooting

### No Changes Showing
- Check if the company is in our monitored list
- Some companies may not have updated their policies recently
- Site blocking might prevent our scrapers from accessing content

### Missing Summaries
- AI summaries are generated on-demand
- Click "Generate AI Summary" if not automatically created
- Use "Choose Model" to select different AI models for analysis
- Some changes may be too minor to warrant summaries
- Rate limiting may delay summary generation (60 requests per minute)

### Slow Loading
- Large diffs may take time to process
- Try refreshing the page if content doesn't load
- Check your internet connection

## Technical Details

PolicyDiff is built with:
- **Frontend**: Next.js 15 with TypeScript
- **API**: Vercel Edge Functions
- **Scraping**: Python Scrapy with Playwright
- **Storage**: Vercel KV and Blob storage
- **AI**: OpenRouter (multiple providers: Google, Meta, OpenAI, Anthropic)
- **Caching**: 24-hour AI summary cache with rate limiting

For technical documentation, see the [Developer Guide](./api.md).
