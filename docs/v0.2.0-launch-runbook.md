# Inplain.ai v0.2.0 Launch Runbook

Purpose: execute and verify launch milestones `L1` through `L15` in a repeatable order.

## 1) Preconditions

- `make lint`
- `make test`
- `make typecheck`
- `make catalog-validate`

## 2) Cloudflare + Clerk hardening (L4 + L5)

Cloudflare:
- Enable orange-cloud proxy for apex + `www`.
- Set SSL mode to `Full (strict)`.
- Keep HSTS enabled at app level.

Clerk Turnstile:
- Enable CAPTCHA in Clerk Dashboard (Turnstile provider).
- Confirm sign-up flow blocks account creation until CAPTCHA passes.

## 3) Railway services (L6 + L7 + L8)

Renderer service (`renderer`):
- Queue scope: `INPLAIN_WORKER_QUEUES=render`
- Disable scheduler + stale-lock cleanup for renderer service.

PostHog service:
- Deploy self-hosted PostHog in Railway project (template services are internal-only).
- Deploy `posthog-proxy` (from this repo) to expose PostHog Web via Railway `$PORT`.
- Set `POSTHOG_UPSTREAM` on `posthog-proxy` to the private PostHog Web URL (including port `:8000`).
- Set `POSTHOG_API_KEY` + `POSTHOG_HOST` (the `posthog-proxy` public URL) on `api` and `worker`.
- Set `NEXT_PUBLIC_POSTHOG_KEY` + `NEXT_PUBLIC_POSTHOG_HOST` on `web` (optional; reserved for client-side tracking).

Sentry:
- Set `SENTRY_DSN` on `api` and `worker`.
- Set `NEXT_PUBLIC_SENTRY_DSN` on `web`.

## 4) Deploy verification (L9 + L10)

Blue-green rollout:
1. Deploy to green.
2. Run smoke checks against green.
3. Switch traffic to green.
4. Monitor for 15-30 minutes.
5. Roll back on errors.

Smoke checks:

If PostHog is configured, include `POSTHOG_HOST` + `POSTHOG_API_KEY` to validate event ingestion.

```bash
WEB_BASE_URL=https://<green-web-domain> \
API_BASE_URL=https://<green-api-domain> \
INTERNAL_SERVICE_TOKEN=<token> \
POSTHOG_HOST=https://<posthog-domain> \
POSTHOG_API_KEY=<posthog-project-api-key> \
make smoke-test
```

## 5) Product/UI launch checks (L12 + L13)

- Diff viewer modes:
  - section-first collapsed view
  - unified view
  - side-by-side view
- Citation behaviors:
  - valid links navigate and highlight
  - unverified citations are visible and disabled
- Marketing pages reviewed for final launch copy (`/`, `/about`, `/pricing`).
