# Contributing

This repo is a clean-slate rebuild. Please read:

- `SPEC.md` (contract)
- `PLAN.md` (milestones + progress log)
- `README.md` (setup + golden commands)

## Pull requests

- Small/medium diffs only.
- Conventional Commits (`feat|fix|refactor|build|ci|chore|docs|style|perf|test`).
- No drive-by refactors or repo-wide formatting unless explicitly requested.
- Update docs when behavior changes (`SPEC.md` if it changes product/architecture, `README.md` if it changes setup, `PLAN.md` if it changes execution).

## Local dev

Use the repo “golden commands” from `Makefile`. Do not invent commands.
